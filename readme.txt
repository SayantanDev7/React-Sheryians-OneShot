1.to use import and export in our index.html in script tag add type = "module"
2.export are of 2 types: named export and default export

3.for named export we use export keyword before the function name
4.for default export we use export default keyword before the function name and in the import we can give any name to the function
5.we can have only one default export in a module
6.we can have multiple named exports in a module   
7.in import for named export we use curly braces {} with the exact function name and for default export we don't use curly braces    

8.eslint.config.js file is used to set the rules for the eslint
eslint is a tool used to find and fix problems in our code
